# GraphQL MongoDB Project

## Descripción
Microservicio para la gestión de productos con búsqueda avanzada utilizando GraphQL y MongoDB.

## Requisitos
- Node.js (v16 o superior)
- Docker (opcional, para MongoDB)
- MongoDB (local o en Docker)
